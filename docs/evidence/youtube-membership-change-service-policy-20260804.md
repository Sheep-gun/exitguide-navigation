## B 내부 튜닝 근거

이 목표를 탐색하며 앱 이름이나 패키지를 하드코딩하지 않고 다음 일반 규칙을 보강했다.

1. 활성 구독 화면에서는 콘텐츠 탭보다 명시적인 외부 구독 관리 게이트웨이를 우선한다.
2. 검증된 관리 게이트웨이가 연 외부 결제 화면은 즉시 중단하지 않고 후보를 다시 평가한다.
3. 희소한 구독 관리 화면의 의미 조합을 인식한다.
4. 일반 `업데이트` 및 결제수단 유지보수는 `membership.change` 목적지로 취급하지 않는다.

관련 코드 커밋은 `217ab4c`, `f4a61b5`, `7ea8762`, `5adcb54`이며, 최신 코드는 N100
운영 8100에 배포돼 있다. 로컬과 N100에서 Navigation API 테스트 10개가 통과했다.
